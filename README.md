# Бюджет — PWA для iPhone + ИИ-разбор скриншотов + Google Таблицы

Схема: **приложение (PWA)** → **Google Apps Script** (в вашей таблице) → **Claude (vision)** → строки в таблице.
Ключ Anthropic хранится только в Apps Script, в приложение он не попадает.

## 1. Google Таблица и бэкенд (5 минут)
1. Создайте новую Google Таблицу → **Расширения → Apps Script**.
2. Вставьте содержимое `apps-script/Code.gs` вместо кода по умолчанию.
3. **Project Settings → Script properties** → добавьте:
   - `TOKEN` — любая длинная случайная строка (пароль к вашему бэкенду);
   - `ANTHROPIC_KEY` — ключ с console.anthropic.com.
4. **Deploy → New deployment → Web app**: Execute as **Me**, Who has access **Anyone**. Разрешите доступы, скопируйте URL (`…/exec`).
   После любых правок кода — Deploy → Manage deployments → Edit → New version.
Лист «Транзакции» создастся сам.

## 2. Приложение
Нужен HTTPS-хостинг статики. Проще всего GitHub Pages: репозиторий → Settings → Pages → ветка, папка `/ (root)`.
Откройте адрес в **Safari** → Поделиться → **На экран «Домой»**.
В приложении: Настройки → вставьте URL и токен.

## 3. Использование
Добавить → выбрать скриншоты (можно несколько) → проверить/поправить категории → Сохранить.
Операции, уже есть в таблице, помечаются и по умолчанию отключаются (защита от дублей при пересекающихся скриншотах).

## 4. «Отправить скриншот» без открытия приложения (Команды iOS)
Команда: *Получить последние фото/Выбрать фото* → *Закодировать (Base64, без разрывов строк)* →
*Получить содержимое URL*: метод POST, URL из шага 1, тело запроса **Файл/Текст** с JSON:
`{"action":"ingest","token":"ВАШ_ТОКЕН","image":"<Base64>","mediaType":"image/png"}`
(для PNG-скриншота; `image/jpeg` для JPEG). Команду можно добавить в меню «Поделиться». Распознанное сразу пишется в таблицу.

## Ограничения
- Категория определяется ИИ по названию мерчанта — иногда ошибается, поэтому есть экран проверки.
- Список категорий задаётся в `Code.gs` (`EXPENSE_CATS`, `INCOME_CATS`).
- Скриншоты уходят в Anthropic API. Если не хотите — закрывайте номера счетов/карт перед отправкой.
- Apps Script: ~6 мин. лимит на запрос, квота UrlFetch; для личного бюджета хватает с запасом.
